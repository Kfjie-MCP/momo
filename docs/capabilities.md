# 能力与 API 来源

服务根据仓库内固定版本的 OpenAPI 注册 34 个业务工具，并补充兼容、聚合及本地复习入口，共 47 个工具。

| 模块 | 业务操作 | 数量 |
| --- | --- | --- |
| 词汇 | 查询单词、批量查询 | 2 |
| 自建释义、助记、例句 | 每类内容的查询、创建、更新、删除 | 12 |
| 云词本 | 列表、详情、创建、更新、删除 | 5 |
| 学习数据 | 进度、队列、记录查询、添加单词、提前复习 | 5 |
| 墨墨记忆卡 | 文件夹列表；卡组列表及详情；章节列表及详情；卡片详情、创建、更新；文件上传、查询 | 10 |

额外入口包括 1 个队列名称别名、2 个现有 API 聚合工具、5 个本地复习工具、4 个状态及 CLI 兼容工具、1 个文档工具。服务还提供 9 个文档资源和 2 个工作流提示。

本地复习工具提供今日抽词、及时事件上报、独立的长期推荐、可翻页单词历史和事件撤回。撤回旧误报会重算相关统计，保留去重标记防止重试恢复。提问与实际错误分别统计，墨墨难记标签不代表已知历史错频。今日权重只使用当天，长期权重使用近期衰减及跨天反复；数据从接入后开始积累，规则见 [复习追踪](review.md)。

Markji 卡片生成由模型参考语法文档完成。服务提供保存等 API 操作，没有额外的上游 AI 生成接口或确定性的语法验证器。

## 接口适配

专用工具直接发送 HTTP 请求。学习模块的 5 个调用路径使用 `/api/v1/study/`，来自固定 CLI 的实现及已有成功请求记录；其他路径沿用 schema。旧版兼容工具仍使用固定 CLI，专用工具是当前 schema 的主要入口。

运行时适配包括：

- 解析 schema 引用，按引用目标处理枚举类型，将 `Object(any)` 转为对象。
- 学习反馈接受 `STUDY_RESPONSE_UNSPECIFIED`；学习记录标签按数组校验，含空数组及已知标签值。
- 添加单词要求非空 `words[].id`，修正来源 schema 缺失的对象类型。
- Markji 创建和更新从请求体读取来源 schema 中缺失的路径 ID。
- 文件上传接受 `body.file = {filename, mime_type?, content_base64}`，通过 multipart/form-data 发送，修正来源文件的 JSON 标注。Base64 上限为 1000000 字符，约 750 KB；更大文件需要另设上传通道。

所有官方响应最多 8 MiB。聚合详情结果也有 8 MiB 上限。请求不会自动跟随重定向或重试，具体队列和批量限制见 [工具说明](tools.md)。

## 数据与认证边界

学习 API 处于公测，依赖 App 当日初始化和自动同步。自建内容查询不包含 App 的全部词典数据。账户权限、订阅限制和官方配额仍然适用。

服务支持请求 Token 和服务端 Token 两种模式，握手只检查入口所需的凭据，不验证墨墨 Token 是否仍有效。Token 会在业务请求时发送到固定官方域名。CLI 本地 auth、config、login、logout 属于服务端管理命令，没有作为远程工具暴露，也不会作为请求级用户的凭据回退来源。

OAuth 登录和自动续期尚未启用。访问 Token 本身不能续期；要支持续期，需要完成应用登记、客户端配置、浏览器授权及隔离的 refresh-token 存储。部署配置见 [部署说明](deployment.md)。

## 验证范围

测试覆盖 34 个业务操作的 HTTP 映射、输入输出校验、写操作确认、multipart 上传、认证隔离、错误分类、MCP 发现和文档读取。聚合测试覆盖队列上限、参数冲突、结果匹配、并发限制、部分失败和批次超时。

复习测试覆盖北京时间日期切换、去重和整批回滚、并发认证及账户隔离、今日与历史分离、真实作答错率、快照替换、重启持久化、版本迁移、长期衰减、跨天困难、冷门词降权、随机抽样、来源缺失和五个工具的 MCP 输出校验。撤回测试覆盖旧事件、各时段重算、最后一条清理、独立快照、重复撤回与上报重试；翻页测试覆盖超过 100 条的历史、相同时间、账户及单词隔离、重启和游标对应事件撤回。

测试使用合成 ID 和模拟响应，类型兼容案例也来自已有问题记录。它们验证实现契约，不代表每个操作都通过了真实账户验证。未知的错误数据仍会被 schema 拒绝。
