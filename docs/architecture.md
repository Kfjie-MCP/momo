# 实现结构

`src/index.ts` 读取配置并启动 Express 服务。每个 MCP POST 请求创建独立的 MCP server 和 Streamable HTTP transport；连接关闭后释放它们，Token 只放在当前请求配置中。

| 文件 | 负责的内容 |
| --- | --- |
| `config.ts` | 环境变量、凭据文件、绑定地址和认证模式 |
| `server.ts` | HTTP 路由、Bearer 认证、健康检查和浏览器跳转 |
| `mcp.ts` | 注册工具、初始化指引、状态和 CLI 兼容入口 |
| `official.ts` | 从 OpenAPI 生成工具 schema，调用并校验官方响应，提供文档资源和提示 |
| `study.ts` | 学习语义、字段说明和冲突筛选检查 |
| `enhanced.ts` | 队列完整性查询和批量详情聚合 |
| `review.ts` | 今日／长期抽词、反馈上报与撤回、历史翻页及本地能力的凭据验证 |
| `review-store.ts` | SQLite 版本迁移、事件及撤回去重、每日快照与统计、长期汇总、历史游标 |
| `errors.ts` | 错误分类和兼容响应封装 |
| `cli.ts` | CLI 参数校验、受控子进程调用、输出限制和凭据脱敏 |

官方调用固定发送至 `https://open.maimemo.com/open`。`official.ts` 根据 schema 处理路径、查询和请求体，设置 Bearer Token，限制超时和响应大小。它保留原始成功数据，验证响应后返回；错误结果保留旧字符串，并添加分类字段。

`enhanced.ts` 复用这些调用。队列工具单次请求最多 1000 条，然后在内存中生成展示范围和完整性信息。详情工具批量查词汇和学习记录，再按词查询用户自建内容，按 ID 关联结果。每批请求限制启动频率、并发数和总耗时。

`review.ts` 的今日入口读取进度与队列，长期入口批量读取 STICKING 标签。今日候选仅使用当天记录，长期候选才读取历史汇总。随机抽取混合风险权重与均匀探索。请求 Token 的成功验证使用仅保存不可逆指纹的 15 分钟内存缓存，原始凭据不写入库。

`review-store.ts` 在进程内按数据库路径共享连接，启动时初始化并执行版本化事务迁移，关闭服务时释放连接。事件由命名空间与 event_id 去重，每日反馈由命名空间、日期和规范化拼写去重。写入或撤回后按时间重放受影响词的观察，重建每日与长期汇总，处理迟到事件和快照替换；没有剩余观察时删除汇总。撤回在同一事务中删除事件正文并保存最小去重标记，旧上报重试不能恢复。历史分页按时间和事件 ID 定位，游标签名绑定凭据命名空间与规范化拼写。数据库使用 WAL 和事务，不保存聊天全文或原始 Token。

原始 OpenAPI 与运行时副本分开保存。`reference/api_bundle.yaml` 是来源快照，学习字段和返回类型的修正集中在代码中。文档资源读取 `upstream-skills/` 的文件，OpenAPI 资源则输出运行时副本。

构建产物在 `dist/`。运行时还需要 `reference/`、`upstream-skills/` 和固定 CLI 的依赖，部署时保留这些目录。代码路径没有依赖文档整理后的 `docs/`。
